# 収益シミュレーション（増益ポテンシャル試算）

> 収支データ②の実数をもとに、「ポチッとデンタル」の仕組み化で見込める**増益ポテンシャル**を試算。
> ポイントは、利益の山谷が激しい **AXiY＋補助金（利益貢献36%）** に依存し切らず、**高粗利リカーリング（サロン95%・HP管理70%）と送客（粗利≒100%）** を3,000名母集団で積み増し、**沈まない利益基盤**を作ること。
>
> ※金額は粗利／純利ベース。送客レイヤーは想定値（要パートナー交渉）。**達成にはファネル整備＋営業オペが前提**。

---

## 1. 現状の利益構造（収支②より）

- **利益の柱はAXiY＋補助金**：補助金（¥3.3M×2年）案件が走った月に利益が急騰（例：ある月 入金¥87.6M／収支¥56.0M・利益率63.9%、大半がAXiY ¥56.2M）。一方、制度依存で**山谷が激しい**（翌々月はAXiY ▲¥4.4M）。
- **高粗利リカーリングが未活用**：
  - オンラインサロン（SDC, ¥3,300/月, **粗利95%**）＝**160名で5ヶ月連続フラット**（3,000名中5.3%）。
  - HP管理（¥11,000/月, **粗利70%**）＝実績まだ僅少（12ヶ月で約¥0.74M）。
- **SLP（ポスティング）は構造的赤字**＝12ヶ月中11ヶ月マイナス（▲¥4,400〜▲¥219,900）。原価60%が主因。
- **採用（KOU/千葉）は黒赤を往復**するが、**KOU紹介料30%＝送客モデルが社内で実証済み**。

→ 改善の打ち手は明確：**①サロン拡大 ②HP管理アタッチ ③送客レイヤー新設**、加えて **④SLPの送客化**。

## 4. 前提と留意

- 送客の単価・成約率は**想定値**。実パートナー交渉とA/Bで補正（`01-routing-priority-master.md` §4）。
- 達成には **(a) お悩み→L0→提案→CVのファネル整備、(b) 送客トラッキング基盤、(c) ホットリードを捌く営業オペ** が必要。
- **個人情報の第三者提供同意**（送客の前提）、広告・景表法（他社サービスの効果表現）、Lステップの友だち数課金（拡大時コスト）を先に手当て。

---

## 5. 推奨：最初の90日（クイックウィン順）

1. **サロン拡大導線**（無料レポート→サロン体験→¥3,300）を全カテゴリ共通の出口に＝即効・粗利95%。
2. **HP管理の全件アタッチ**＋既存HP客へ一斉提案＝沈まない月額の積み上げ。
3. **補助金フック（AXiY）を「集患・DX・経営」導線の主CVに**＝利益貢献36%の最大化。
4. **送客の課金モデル整備**（KOU30%を雛形に契約・トラッキング標準化）＆ **SLP送客化**。
