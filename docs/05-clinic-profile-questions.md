# 医院カルテ 質問項目 ＆ Lステップ タグ設計（STEP1）

> 登録時に**1回だけ**聞く質問。ここで集めた情報が「その先生にピッタリのサービスを自動で出し分ける」土台になり、
> [`01-routing-priority-master.md`](./01-routing-priority-master.md) の関連度フィルタと [`03-push-segmentation-triggers.md`](./03-push-segmentation-triggers.md) の配信条件にそのまま使われる。
>
> Lステップでは2種類に分けて保存する：
> - **友だち情報欄**（自由記入）… 送客フォームに**差し込んで自動入力**するための情報（医院名・連絡先など）
> - **タグ**（選択式）… 出し分け・セグメント配信に使うラベル（悩み・規模・導入ツールなど）

---

## 2. タグ設計一覧（出し分け・配信の素）

選択式の回答は、下記タグに変換して保存する。機械可読版は [`../data/clinic-profile-tags.csv`](../data/clinic-profile-tags.csv)。

| タグ分類 | タグ値（例） | 使うシーン |
|---|---|---|
| エリア_都道府県 | 東京都／大阪府／… | 地域型送客・開業・ポスティング |
| 開業年数 | 1-3年／4-9年／10年以上 | 1-3年=集患、10年以上=採用・DX・継承 |
| 規模_チェア台数 | 1-2／3-4／5以上 | 規模に応じた提案 |
| 規模_スタッフ数 | 〜5／6-10／11以上 | 採用・教育の出し分け |
| 患者数_日 | 〜20／21-40／41以上 | 集患の濃さ判定 |
| 自費率 | 〜10%／10-30%／30%以上 | 低い→自費・口コミ×DX案内 |
| 導入_電子カルテ | あり（製品名）／なし | なし→電子カルテ送客 |
| 導入_アポ帳 | クラウド／紙・オンプレ／なし | クラウド以外→アポ帳送客 |
| 導入_キャッシュレス | あり／なし | なし→決済送客 |
| 悩み_◯◯ | 集患／採用／DX／お金／自費／継承（複数可） | **トップメニューと初回提案の出し分け** |
| 志向 | 拡大／維持／継承 | 継承=事業継承、拡大=集患・採用 |
| 同意_第三者提供 | 済／未 | 「済」のみ送客対象に含める |

## 3. 同意（第三者提供）の扱い ― 送客システムとの接続

質問15の同意が、[`06-referral-system.md`](./06-referral-system.md) の**ワンクリック送客の前提**になる。

- **登録時に一括同意（タグ:同意_第三者提供=済）**を取れば、以降は**毎回の確認なしでワンクリック送客**できる（情報入力ゼロ）。
- 「未」の先生には、初回の送客時に**1回だけ確認**を挟む（同意したら「済」に更新）。
- 同意は**いつ・どの範囲で取得したかのログ**を残す（個人情報保護のため）。
- パートナーに渡すのは**必要最小限の項目のみ**（医院名・地域・担当・連絡先・お悩み・送客ID）。

## 4. Lステップでの作り方（かんたん手順）

1. 「友だち情報欄」に **医院名・担当者名・市区町村・電話・メール・開業年** を作る（差し込み用）。
2. 「タグ」に上記タグ分類を作る。
3. **回答フォーム**で質問1〜15を作成。名前など既知の項目は**友だち情報を初期値に自動入力**（タップ負担を減らす）。
4. 回答に応じて**自動でタグが付く**よう設定（例：「自費10%未満」→タグ:自費率_〜10%）。
5. 登録完了したら、リッチメニューの「お悩み」へ誘導。

---

## 5. 最初の30日でやること（カルテ版）

1. 必須（◎）の8項目だけで回答フォームを作る（まず軽く始める）。
2. 質問13（お悩み）と質問15（同意）は**必ず入れる**＝出し分けと送客の心臓部。
3. 友だち情報の差し込みをテストし、「ほぼタップだけ」で進むか確認。
4. 既存の約3,000名には、カルテ未入力者へ**一斉に登録のお願い**を配信（プロフィール補完キャンペーン）。
