## 基本コンセプト

1. **関連度ファースト × 粗利重み付け** … 医院プロファイルで適合フィルタ → 実利益のランク順に提示。
2. **価値提供ファースト** … 提案前にL0（無料レポート・診断・ツール）で信頼を構築。
3. **高粗利リカーリングを必ず絡める** … オンラインサロン(95%)・HP管理(70%)を全導線でクロスセル。
4. **自社で稼ぎ → 送客で稼ぎ切る** … 自社に解が無い／赤字の領域は掲載料＋成果報酬の送客へ。

## 出典データ

- サービス設計マスター（`ポチッとデンタル` スプレッドシート）… お悩み→サービスの対応関係
- 各事業の収支データ … 単価・原価・利益率・利益貢献度（ランク付けの根拠）

## 次工程

- 医院プロファイル＝Lステップのタグ項目設計（関連度フィルタの入力）
- リッチメニュー／シナリオ分岐への落とし込み（01のルーティング表を条件分岐に）
- 送客トラッキング基盤（専用フォーム＋UTM）と、パートナー課金（掲載料×成果報酬）の契約整備

> ※金額・想定値は出典データおよび仮置きに基づく。送客単価等は実パートナー交渉で確定する。
